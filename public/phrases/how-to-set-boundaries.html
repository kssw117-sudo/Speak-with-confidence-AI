How to set boundaries without guilt

Clear boundaries protect your time and energy. These lines help you say what is okay and what is not, kindly but firmly, at work and in personal life.

Three things that help most
  • Use calm, short "I" statements.
  • You do not need to justify a boundary at length.
  • Repeat the same boundary calmly if it is tested.

40 phrases you can use

  • I need some time for myself this evening.
  • I'm not comfortable talking about that.
  • Please knock before you come in.
  • I won't answer work messages after seven.
  • I love spending time with you, and I also need some space.
  • I'm not able to lend money right now.
  • Please don't comment on my weight.
  • I'd like you to ask before borrowing my things.
  • That joke hurt me. Please don't make it again.
  • I'm going to leave now, because this conversation isn't going anywhere.
  • I'd prefer to talk about this when we're both calm.
  • I'm not going to discuss my salary.
  • I need you to respect my decision.
  • I can stay for one hour, then I need to go.
  • Please don't share my personal information with others.
  • I'm not available this weekend.
  • I'm happy to help, but not every day.
  • I need you to call before visiting.
  • I'm not okay with being spoken to like that.
  • I'd rather not answer that question.
